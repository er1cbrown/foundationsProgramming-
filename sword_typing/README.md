# Bible Sword Typing

A typing practice game built around Bible passages, with a sword theme.

## Play

Open `index.html` in a browser. Images (`bg.jpg`, `sword.jpg`, `warrior.jpg`) must stay in the same folder.

## Levels

- **Easy** - short verses
- **Medium** - common passages
- **Hard** - longer passages, including sword-themed verses (Hebrews 4:12, Ephesians 6:17)

## Scoring

Each round reports WPM, accuracy, and perfect-hit status. The final screen gives a sword-themed rank based on average accuracy.
